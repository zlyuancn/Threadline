### 复审期间的三次真实构建验证

1. `pnpm tauri build` 首次执行即失败：`no release tl-core.exe`（`bundle-sidecars.ps1` 只接受 release，而当时只有 debug 构建）——正是复审二 A3 预言的「干净 clone 卡点」。
2. 补齐后构建成功：`src-tauri/target/release/Threadline.exe`(10.0 MB)、`tl-core.exe`(9.5 MB)、`bundle/nsis/Threadline_0.1.0_x64-setup.exe`(6.46 MB)，`mainBinaryName` 生效。
3. `7z l` 解包确认安装包内含 `LICENSE`、`THIRD_PARTY-NOTICES.md` 与 7 个 `licenses/*.txt`（MPL-2.0 ×2、ring ×3、Unicode ×2），字节数与源文件逐一相等。

### 遗留 P2（不阻塞发布，记录在案）

- `release.yml` 的 `permissions: contents: write` 可下沉到 `build` job；`ci.yml` 缺显式 `permissions`；
- 导出无脚本固化（见决策 0003「单次导出」），建议长期补 `subtree split` 脚本；
- `scripts/verify.sh` 索引模式为 `100644`，Linux/WSL 下不可直接执行；
- 发版不校验 tag 与版本号一致（首次 `v0.1.0` 不触发）；
- `scripts/shot.ps1` 非 ASCII（开发辅助，不被门禁调用）。
