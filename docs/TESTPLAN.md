# TESTPLAN（功能测试项清单）

> 新增/修改功能须同步维护。本机门禁见 `scripts/verify.sh`；标 **[环境]** 的项必须在真实 SSH 服务器 / 真实安装环境实测。

## 一、端口转发核心

| 编号 | 测试项 | 期望 | 层级 |
|---|---|---|---|
| T-01 | 单条 `-L` 隧道启动 | 本地端口监听成功，访问即到达远端端口 | [环境] |
| T-02 | 多条隧道并存 | 各隧道独立监听与状态，互不影响 | [环境] |
| T-03 | 单隧道停止 | 释放本地监听，其它隧道不受影响 | [环境] |
| T-04 | 首次绑定端口被占用 | `Error(local_port_in_use)` + `field=local_port`，不影响其它隧道 | 本机 |
| T-05 | SSH 认证失败 | `Error`，区分密钥被拒 / 密码错误 / 服务器不允许该方式 | 本机 |
| T-06 | 网络中断后恢复 | `Backoff` 有界退避；**监听全程保持**；恢复后回 `Running` | [环境] |
| T-07 | 远端端口不可达 | 单次连接失败，不触发隧道整体重连 | [环境] |
| T-08 | 并发连接 | 多连接同时打进去，数据不乱序、不串流 | [环境] |
| T-09 | keepalive 失效 | 服务器静默后 ≤90s（3×30s）从 `Running` 转 `Backoff` | [环境] |
| T-10 | `Backoff` 期间新连接 | 立即关闭（快速失败），不挂死、不排队 | 本机 |
| T-11 | 连续 10 次重连失败 | 转 `Error` 并停止自动重连；手动重试可恢复 | [环境] |
| T-12 | 主机密钥未知 | 停在 `NeedsTrust` 并展示指纹；确认后进 `Running`；拒绝则 `Stopped` | [环境] |
| T-13 | 主机密钥不匹配 | `Error(host_key_mismatch)`，绝不自动接受 | [环境] |

## 二、CAW 不变量

| 编号 | 测试项 | 期望 |
|---|---|---|
| C-01 | 核心无头 | `tl-core`/`tl-wake` 无任何 GUI 依赖（msocheck R4 拦截）；零登录会话下能启动并服务 |
| C-02 | 核心不弹 UI | 运行期无窗口、无托盘、不开浏览器 |
| C-03 | Wake 每条路径都退出 | 核心在 / 自启关（拉起 `--manual`）/ 自启开但起不来（拉起 `--stand-in`）/ 拉起失败 / Agent 失败，均 ≤20s 退出，退出码符合设计 §3.6 |
| C-04 | Agent 崩溃零损失 | 杀 `tl-agent`，转发不中断；恢复方式 = 再运行 `tl` |
| C-05 | 至多一个核心 | 连点两次 `tl`，只产生一个 Core；第二个退出码 3 |
| C-06 | 每会话至多一个 Agent | 连点两次唤起，只弹一个面板 |
| C-07 | 自启开关不停服务 | 开/关自启期间，正在跑的隧道不断、Core 不重启（I5） |
| C-08 | 低权限停高权限 | 用户身份 Agent 通过 `POST /shutdown` 让 SYSTEM Core 优雅退出 |
| C-09 | 无旁路 IPC | Agent/Wake ↔ Core 只走回环 HTTP（Agent 自身的会话内单实例管道不属此面） |
| C-10 | 开关切换生效 | 开启 → 重启后 SYSTEM 核心在未登录时已在跑；关闭 → 重启后不再自启 |
| C-11 | 注册物归属 | HKCU `Run` 项属于**交互用户**（不是 SYSTEM 蜂巢）；任务计划只由 Core/安装器写 |
| C-12 | 顶班可见 | 自启开着但 SYSTEM 核心起不来时，Wake 拉起用户身份核心并标 `stand_in_core` |
| C-13 | 降级可见 | `stand_in_core` / `fallback_run` / `credential_acl_relaxed` / `credential_unreadable` / `local_port_lost` 在 API + UI + 日志均可见 |
| C-14 | 注册前置校验 | 路径非绝对或无日志去向时报错并指明字段名 |
| C-15 | 控制端口全占 | 18921–19020 全占 → 退出码 5，日志写明 |
| C-16 | 停止服务语义 | `POST /shutdown` 后 Core 退出码 0；自启开关状态不变；本次开机不再自动起；重启后照常自启 |

## 三、凭据与安全

| 编号 | 测试项 | 期望 |
|---|---|---|
| S-01 | 加密落盘 | `credentials.dat` 内无明文（字符串检索不到密码与私钥内容） |
| S-02 | 两身份均可解 | SYSTEM 写→用户读、用户写→SYSTEM 读，两个方向都成功 |
| S-03 | ACL | 非授权用户读不到 `credentials.dat`；`control.json` 只读、`core.lock` 可读写 |
| S-04 | token 鉴权 | 无 token / 错误 token 调受保护端点 → 401 |
| S-05 | 仅回环 | 局域网其它机器访问控制端口不可达 |
| S-06 | 实例身份校验 | 别的程序占用 `control.json` 里的端口时，`instance_id` 比对失败 → 判「不是我们的核心」并走拉起分支 |
| S-07 | 凭据更新 | `PATCH /credentials/{id}` 能改密码/口令，响应不回显任何密钥字段 |

## 四、桌面体验

| 编号 | 测试项 | 期望 |
|---|---|---|
| U-01 | 托盘常驻 | 托盘出现，菜单含各隧道状态与开关 |
| U-02 | 灰态与重挂 | Core 不可达时灰态，恢复后自动重挂 |
| U-03 | 快捷唤起 | 双击 `tl`（或快捷方式/热键）秒开面板 |
| U-04 | 自启（开） | 未登录时 Core 已在跑，登录后托盘出现 |
| U-05 | 卸载清理 | 卸载后任务计划、HKCU `Run` 项、数据目录按选择清理，无残留 |
| U-06 | 提权引导 | 用户身份 Core 改自启开关时返回 `409 privilege_required`，UI 横幅 + 一键重试，只弹一次 UAC |
| U-07 | 面板跨源可达 | WebView 页面源（`http://tauri.localhost`）能读到核心响应：预检（带 `authorization`）返回 200 且带 `Access-Control-Allow-Origin`；普通响应同样带该头 |
| U-08 | 异步按钮状态 | 启停/刷新/行内操作/保存/自启开关：执行中转圈并禁止再次点击；超过上界提示超时；失败后可重试 |
| U-09 | 合计速率不残留 | 隧道全部停止或删除后，侧栏合计速率立即消失，不出现「0 条隧道正在运行却挂着 ↑/↓」 |
| U-10 | 侧栏核心状态块位置 | 位于「N 条隧道正在运行」与「快速呼出」之间；状态+刷新+版本同行、合计速率独占第二行；208px 侧栏下不换行、不溢出 |
| U-11 | 「应用」页导航入口 | 侧栏顺序为「应用 → 所有转发 → 日志 → 设置」，默认停在应用；只显示 `in_app` 未关闭的转发；按转发自己的 `group` 字段分组（空归「未分组」置末，组序按首次出现）；图标优先用自定义 `icon`，其次入口站点 favicon（运行中才请求），最后回退协议图标（ssh/rdp/tcp）；只展示本地访问方式（web 为完整 URL，其余为 `host:port`）；运行中的 http/https 整块可点并打开浏览器，停止时与 tcp/ssh/rdp 均不可点且 title 说明原因；「…」菜单的启动/停止/编辑/删除均可生效 |
| U-12 | 转发的图标与分组可编辑 | 编辑弹窗含「分组」（可选择已有或直接输入新值）、「图标」（导入 URL / 本地文件后保存为 128px 本地 data URI，留空回退自动）与「添加到应用」开关；保存后磁贴立即按新分组归位、显示新图标；清空后回到未分组 / 自动 favicon |
| U-13 | 图标导入落本地 | 填远程图标地址点「导入」或选本地图片后，图标被缩到 128px 并以 `data:image/png` 存入配置；断网后应用页仍能显示；远程图超过 4MB 时导入失败并提示；保存表单时若 icon 仍是 http(s) 地址会自动落盘 |
| U-14 | 「所有转发」页（按隧道） | 恢复为按隧道分组的 `ForwardCard` 列表，展示全部转发（不受 `in_app` 影响）；启停开关、远端→本机映射、编辑/删除按钮与首页一致；搜索支持名称/备注/IP/端口/隧道名 |
| U-15 | 卡片图标与磁贴同源 | 首页与「所有转发」页的卡片图标遵循同一优先级：自定义 `icon` → 运行中 web 转发的站点 favicon → 协议图标；停止时不请求 favicon，加载失败自动回退协议图标，换图标或启停后重试；显示图片时去掉图标框的描边与底色 |
